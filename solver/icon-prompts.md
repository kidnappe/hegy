# 何解 · 图标生成提示词（扁平插画套用版）

> 需求来源：截图里那套「扁平卡通 UI 图标组」提示词，按其三段式（风格 / 图标元素 / 排列）套到「何解」项目上。
> 品牌：中文「何解」，英文 **Hegy**（包名 hegy、appId com.hegy.app）。
> 主色：靛蓝 `#5b5bd6`；UI 背景 `#f4f5f7`，边框 `#e4e7ec`；画布纯白。

---

## 一、应用图标（.ico · 三角形重心方案）

**风格**：扁平几何标志，靛蓝紫圆角方块底，白色线条，无文字、无渐变、无光影、无阴影，圆角外透明。

**图标元素**：白色三角形 + 中心点连向三个顶点（重心 / 中线意象），整体像一道正在被构造的几何题。

**排列**：1 图标居中独立呈现，四周留白均匀，图标本体占画布约 80%，背景不添加任何装饰文字。

**使用**：1024×1024 PNG 母版 → 7 档 ICO（16–256，256 档用 PNG 压缩）→ 同步 `desktop/build/icon.*` 与 `solver/assets/icon-*`。

---

## 二、界面功能图标组（按「何解」真实功能重写）

**风格**：扁平卡通 UI 图标组，无描边矢量风格，所有图标统一做圆润无棱角的萌系极简造型，明亮活泼的高饱和马卡龙撞色，纯平涂色块，无渐变、无光影、无阴影

**图标元素**：解题（灯泡 + 笔）、动态几何（三角形 + 一个动点）、立体几何（正方体）、对象面板（列表 + 色点）、步骤讲解（播放三角 + 分段条）、测量（直尺 + 角度弧）、导出（向下箭头 + 文件）、历史记录（时钟 + 文档）、设置（齿轮）、微调（画笔 + 魔法星）

**排列**：共 10 个图标整合在一起，均匀排列成 5×2 矩阵，每个图标下方配有对应中文功能标签，不要括号中的文案，整体纯白色干净背景

**标签**（按矩阵顺序，左→右、上→下）：解题 / 动态几何 / 立体几何 / 对象面板 / 步骤讲解 // 测量 / 导出 / 历史记录 / 设置 / 微调

---

## 三、启动图（横版）

**风格**：深藏青底（`#111433` 一带）的几何插画，细线构造感，白色 / 靛蓝紫线条，无渐变、无阴影。

**图标元素**：左侧「何解 / Hegy」字标；右侧用四步递进展示同一个三角形的构造过程（顶点 → 中线 → 重心 → 完成）。

**排列**：横版 560×340（2x 源图 1120×680），左侧字标、右侧构造图，整体留白充足。

**文案**：「正在解压程序文件，请稍候」，不写「首次」。

**使用**：导出 `splash.bmp`（24bpp）+ `splash@2x.png`，放在 `desktop/build/`，由 electron-builder 的 portable 配置引用。

## 五、竖版宣传图组（1080×1920 一组 4 张）

**风格**：扁平卡通 UI 插画，无描边矢量风格，圆润无棱角，高饱和马卡龙撞色，纯平涂色块，无渐变、无光影、无阴影

## 六、套用说明

| 原提示词字段 | 套用到本项目 |
|---|---|
| 风格行 | 原样保留（扁平/无描边/圆润/高饱和/纯平涂/三无） |
| 图标元素 | 换成「何解」的真实功能与真实对象名（解题、动态几何、立体几何、对象面板、步骤讲解、测量导出、历史、设置、微调） |
| 排列 | 保留「N 个整合、均匀矩阵、下方中文标签、不要括号文案、纯白背景」的写法，只改数量和矩阵形状 |
| 颜色 | 原提示词只写「高饱和马卡龙撞色」，本项目额外钉死主色 `#5b5bd6`，避免图标与 UI 撞色 |

### 可调参数（换场景时只动这几个）
- **N**：图标个数（原版 10，可改 8/12）
- **矩阵**：`5×2` / `4×2` / `6×2`
- **主色**：`#5b5bd6`（改则同时改 UI）
- **背景**：`纯白色` 或 `浅灰白色 #f4f5f7`
- **标签**：按矩阵顺序一一对应，用「/」分隔，`//` 表示换行
