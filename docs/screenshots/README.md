# 文档截图

这些图用于 README 和开发文档，均从真实运行的「何解」界面截取。

|---|---|
| `2d-solve.png` | 2D 解三角形：对象面板、画布、答案与分步解析 |
| `3d-solve.png` | 3D 立体几何：可旋转图形、多小问、微调区 |

## 注意

- 截图里的 API Key 一律是虚构的，没有使用真实 Key。
- 新增截图前请检查：不要出现真实 Key、用户名、本地路径、用户记录、个人题目信息。
- 控制文件体积；优先用 PNG，宽度 1360px 左右即可。
- 截图只放在 `docs/screenshots/`，不要把 `docs/manual/` 的生成图和临时截图提交进仓库。
